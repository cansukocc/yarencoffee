# Proje Kapsamı

## Case study gereksinimleri

**Görsel kimlik**

- Renkler: kırık beyaz `#F5F0E6`, koyu kahve `#3B2418`, zeytin yeşili `#6B7045`.
- Ahşap doku, sade tipografi, kahve fotoğrafları.

**Giriş bölümü**

- Marka adı.
- "Her fincanda ortak bir hikâye." sloganı.
- Ürünlere kaydıran "Kahveleri Keşfet" butonu.

**Ürünler**

- Türk Kahvesi, Espresso, Filtre Kahve.
- Her biri için görsel, kısa açıklama ve örnek fiyat.

**İletişim formu**

- Alanlar: ad, e-posta, mesaj.
- Boş alan ve e-posta biçimi kontrolü.
- Geçerli gönderimde başarı mesajı.

## Teslim

- Kaynak kod.
- Kısa çalıştırma adımları.
- Canlı link.
- 3-4 cümlelik araç açıklaması.

## Tasarımdan farklı olarak yapılacak düzeltmeler

1. Form doğrulaması istemcide JS ile çalışacak, sunucuda Form Request ile tekrar edilecek.
2. Çalışmayan "Sepete ekle" butonu yerine ürün adını mesaj alanına yazıp forma kaydıran bir buton olacak.
3. Görseller WebP'ye çevrilecek.
4. "Yeni mesaj gönder" sayfayı yenilemeden formu sıfırlayacak.
5. Vercel Analytics kaldırılacak; fontlar npm ile yerel, ikonlar inline SVG Blade bileşeni olacak.

## Admin paneli kapsamı

- Giriş.
- Ürün yönetimi: ad, açıklama, fiyat, not, görsel.
- Site metinleri: slogan, hero, iletişim bilgileri.
- Gelen mesajlar: listele, okundu, sil.

## Kapsam dışı

Sepet, ödeme, üyelik, çoklu dil.
